使用方式

1观战台：浏览器已自动打开，直接在这里看实时对局。
2模型管理：添加 API 配置（地址 + Key），拉取并勾选要用的模型。
3游戏配置：选板子 → 给每个座位分配模型（可 🎲 随机）→ 开始游戏。
4回放：对局结束后可随时回看整场。
